# IWCare 웹사이트 초안 — 스마트 약장 (MediHome)

정적 HTML 한 페이지 + 로고 렌더러. 빌드 없이 그대로 배포할 수 있습니다.

## 구성
- `index.html` — 메인 페이지 (v4 브랜드 시스템 기반, 스마트 약장 중심 재편본)
- `brand/logo.js` — IWCare Joy Monogram 로고 렌더러 (필수)

## 미리보기
`index.html`을 브라우저에서 바로 열면 됩니다.

## 무료 배포 방법
- **Netlify Drop**: https://app.netlify.com/drop 에 이 폴더(또는 zip)를 드래그 → 즉시 URL 발급
- **GitHub Pages**: GitHub 저장소에 파일 업로드 → Settings → Pages → Branch `main` 선택 → Save
- **tiiny.host**: 이메일 가입 후 `index.html` 업로드
